# AZ Hearts In Homes

> **Real Estate With Heart**

AZ Hearts In Homes is a modern, relationship-focused real estate platform built for Arizona home buyers and sellers.

Unlike traditional real estate websites, this project emphasizes trust, communication, and storytelling while delivering a premium user experience.

# Development

Install packages

```bash
pnpm install
```

Run locally

```bash
pnpm dev
```

Production build

```bash
pnpm build
```
